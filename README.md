# Abdulrahman Bashir — Personal Website

## Files
- `index.html`: page structure and content
- `css/style.css`: all site styles
- `js/script.js`: interactive behavior and settings logic

## Run locally
Open `index.html` in a modern browser. The website is static and does not require a build step.

## Important notes
- Settings are stored in the current browser using `localStorage`; they do not sync across devices.
- The settings password gate is client-side only and is not secure authentication for a public website.
- The contact form opens the visitor's email application; it does not send messages through a server.
